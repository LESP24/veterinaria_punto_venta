# 🛒 Veterinary Point of Sale (POS) System

> A complete, custom-built Point of Sale application designed to manage transactions, ticketing, and sales cancellations for a veterinary clinic. This project demonstrates full-stack capabilities, separating business logic, database management, and user interface.

## 🚀 Features
* **Sales Management:** Process transactions and issue detailed receipts/tickets.
* **Order Modification:** Built-in logic for secure sales cancellation and inventory/cash adjustments.
* **Modular Architecture:** Clean separation of `frontend` (UI), `backend` (business logic), and `data` (database management) modules.

## 🛠️ Tech Stack
* **Language:** Python
* **Database:** SQLite *(Modifica esto si usaste MySQL, PostgreSQL o JSON)*
* **GUI Framework:** Tkinter / PyQt *(Escribe aquí la librería que usaste para la interfaz gráfica)*
* **Architecture:** MVC (Model-View-Controller)
